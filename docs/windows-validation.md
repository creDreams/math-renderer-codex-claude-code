## 安装交付

`dist/releases/` 提供单个 Setup.exe 与便携 zip，约 40 MB。解压后约 110 MB；准确字节数与 SHA-256 见 `release.json`、`SHA256SUMS.txt`。包含固定 Node.js `24.19.0`、MathJax/NewCM `4.1.3`、resvg-js `2.6.2`；不依赖机器上的 Chrome、Node、npm 或源码。原生宿主使用 Windows 系统 .NET Framework。

安装器默认安装到 `%LOCALAPPDATA%\Programs\AgentMath`，只注册当前用户，无需管理员权限。登录启动默认关闭。托盘可以退出；Windows 应用列表和安装目录的 `Uninstall.exe` 都可卸载。更新/卸载保留 `%LOCALAPPDATA%\AgentMath` 用户设置，不碰 Codex 和 Windows Terminal 配置。

根目录 `Start Agent Math.cmd` 已手动启动验证，worker 就绪；重复启动仍保留同一宿主进程。安装版/便携版共用默认用户配置，因此使用其中一种入口即可。

## 尚未验收

- 独立 Windows 机器、代码签名、社区发布；当前安装包仅在开发机的独立临时目录验收。
- 混合 DPI、多显示器、透明终端、管理员终端、WSL/SSH、其他 agent/终端。
- 真实工具审批：目前只有合成审批重绘及真实 Codex 输入/输出/中断检查。
- 超过上述基准规模的极长会话、多个 Codex 自定义 home 同时运行、大规模高频输出和长期运行压力。

完整公式必须可见，来源证据可来自当前视口及有界前方正文，并且能在本地会话中唯一匹配。Windows .11 不再按文件数、回答数或尾部字节限制历史；助手标记超出前方上下文范围、单条记录超大、空间不足或未知 UIA 状态仍可能保留源码。无法确认时撤掉覆盖，供用户继续使用终端。

可见说明包含尚未支持的排版转换时，也可能无法精确匹配。当前支持简单矩形管道表格；含转义管道或复杂布局的表格保留严格原文要求，未识别的原生字符公式转换也会使匹配失败。
