# 0001：在宿主呈现层增加视觉覆盖

状态：已接受，2026-11-02。

适用范围更新：本文记录已经验证的 Tabby 实现。后续社区产品需按[产品方向](../product-direction.md)重新评估宿主接入；不将更换为 Tabby 作为默认使用前提。呈现层增强与保持原始交互的约束继续保留。

采用 Tabby 插件与独立 xterm.js addon。Tabby 继续管理 PTY、输入、窗口与进程；插件从逻辑缓冲区读取公式，使用 MathJax 排版为 SVG，在原字符区域内覆盖显示。

禁止通过终端 write、PTY output filter 或重新发送控制序列来替换公式。原始字符与光标状态保留，复制默认取得源码。

首版优先完整块公式。所有覆盖必须在底层区域变化或插件关闭时失效。无法确认位置和语义的内容保留原文。

宿主内部接口集中封装并做能力检查。首个验收是实际 Tabby 加载/卸载与原位显示；未通过前不将浏览器静态演示声明为宿主支持。
