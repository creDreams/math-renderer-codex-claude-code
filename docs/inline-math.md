# 行内公式预览

版本：`0.2.0-preview.23`。Windows Terminal / 本地 Codex 主线提供可选的行内公式显示。托盘勾选 **行内与无标记公式（预览）** 后生效；初始默认关闭，设置会保留。仍照常运行 `codex`，无需修改提示词或输入输出路径。已运行的组件也可用 `AgentMath.exe --inline-on` / `--inline-off` 切换。

## 识别范围

优先识别 `\(...\)` 和 `$...$`。无标记文本先排除代码、路径、URL、命令、配置、日志等，再通过有界语法分析检查完整性和数学特征，不调用模型或联网服务。

| 输入例子 | 当前处理 |
| --- | --- |
| `\(x^2+y^2=r^2\)`、`$x^2$` | 明确的行内边界优先；金额文本另行排除 |
| `x² + y² = r²`、`Âₜ = Qₜ − Vₜ` | 可识别并核对来源，但保留已易读的原生字体和间距 |
| `f(x) = x^2 + 1`、`θ_{t+1} = θ_t − α∇J(θ_t)` | 存在原始脚本时增强；仍需满足完整语法、来源和几何约束 |
| `L_total(θ) = E_t[L_CLIP(θ) - c₁L_VF(θ) + c₂S[π_θ](s_t)]` | 支持常见损失函数写法；仍需在同一物理行内且能放下 |
| 无包裹的 `\frac{a+b}{c}`、`\sqrt{a+b} = x²` | 仅接受白名单命令及完整参数 |
| `x=1`、单独的 `θ`、`timeout=30`、金额/日期/版本/路径 | 保留原文 |
| `x_ij + y² = r²`、未闭合括号、未知命令 | 含糊或不支持，保留原文；不截取后半段勉强渲染 |

数学上下文可增加证据，但“公式”等提示词本身不足以通过。语法不做计算，不将 `a/b` 擅自改成垂直分式，不把 `E` 猜成黑板体期望，不更改 Unicode 数学字母样式。普通花括号保持可见；TeX 参数和下标花括号保持分组。有限的无括号下标标签（如 `total`、`CLIP`、`VF`、`prior`）按约定处理；未支持的多字母下标保留原文。

.20 将识别与是否值得覆盖分开：最终可见文本没有 `_`、`^`、反斜杠或美元分隔符时，保留原文。显式标记若仍可见会参与渲染；若 Codex 已将其转成清楚的 Unicode，则不再缩小重画。原位覆盖不能回收终端原有字符占位，不为了填满空白拉伸数学字形。

截图中的多行字符求和、分式和边框属于块公式。对仍含原始脚本的转换块沿完整来源证明定位，使用会话中的规范 TeX 整体绘制。.22 起，这类可见文本没有块标签的图片也受预览开关控制，关闭时连同已有缓存图片一起撤下；仍可见 `\[...\]`、`$$...$$` 或块环境的公式继续由总开关控制。Codex 自身输出的字符数学仍是终端原文，关闭插件预览不会将其还原为 LaTeX。不能从零散的 `_` 猜一整条公式，也不能覆盖共享同一行的正文。仅有可见片段证明而缺少完整位置映射时保留原文。

无法从纯文本绝对区分数学与代码，例如脱离代码标记的 `a = b + c`。此功能不承诺任意模型输出零误识别；独立预览开关用于逐步验证实际使用反馈。生成语料的零误报只代表所覆盖的样本。

## 来源和位置

检测结果只是候选，不能直接绘制。必须先与本地助手回答及可见上下文唯一核对，再把原始公式出现位置沿同一次证明映射到终端。代码即使隐藏反引号、且内容与真正公式相同，仍受保护。用户输入、工具输出、来源歧义和修改后的文字不能借用相同公式的旧证明。

测试示例应放在助手的普通正文中。用 Markdown 反引号包住的表达式属于代码，即使终端不显示这些反引号，也会保留原样；开启行内开关不会取消代码保护。

初版仅覆盖**完整处于同一终端物理行**的公式。软换行跨越多行、公式被裁切、表格经过字符排版转换、原位宽高不足时保留原文。不重排终端文字，不遮盖邻近标点，不以过度缩小换取显示。窄窗口中的长 PPO 表达式可能因此保持原样。

位置使用 UIA 实际子串矩形，UTF-16 文本偏移不当作终端列宽或 UIA Character 单位。Windows Terminal 1.24 的 `FindText` 可能额外包含后一格，定位器改用经核对的后缀起点作为排他边界。中文、emoji、组合重音、数学字母及同一行重复公式均有独立几何检查。

图片按行内样式排版，优先对齐估算基线。.22 提高字号上限，并在原行高度内放大：28 px 行高下，普通平方公式的图片高度由 22 px 增至 26 px，示例策略更新和 PPO 损失由 21 px 增至 26 px；同时带上下标、原本已占满行高的公式不会继续增大。允许基线最多偏移行高的 15%，上下各保留至少 1 px，字号下限不降低。图片宽度仍须放入精确的原始子串区域，不能为加大字号遮挡正文，放不下则保留原文。鼠标继续穿透到终端；实际选区触及某条公式时，只撤下该区域的图片，复制获得原始终端文字。流式输出仍沿用已核验、未变前缀的短暂保持规则，不延长来源期限。

.23 进一步针对细符号和脚标优化：在主体缩放、基线和宽度都允许时，将脚标相对主体的比例从约 0.707 提高到 0.82；用轻微的字形描边增强细笔画，不改换粗体变量或字体变体。描边有独立留白，防止切掉边缘。拟合缩放系数须保留原布局的至少 94%，图片不得比旧布局更宽，且须通过原基线约束；不满足时依次尝试原脚标比例的清晰描边和原布局，避免为放大造成漏显。默认与清晰脚标 SVG 使用独立缓存键，块公式沿用原布局。

已经占满原行的复杂公式无法在不遮盖正文的情况下整体继续放大。在 Windows Terminal 中可按住 **Ctrl 并向上滚动鼠标滚轮** 增大终端字号和行高，组件会按新行高重新排版。这会同时放大终端文字。当前没有增加悬停或按键放大浮窗。

.19 关闭 MathJax 的行内 SVG 分片，并要求一条公式生成一个完整 SVG，防止只显示第一个操作数。终端接口把自动折行合并为逻辑文本时，按 UIA 的物理行边界重新读取，逐行核对矩形和完整文本；不能根据 UTF-16 长度猜测列宽。末尾空行不能掩盖恰好一次软换行，空白区域也必须与原始文本和剩余行数一致。

自动滚动只改变某行的纵坐标时，行内几何缓存可随当前行平移，避免先撤图再重新查询。复用仍要求窗格、字体、整行文字、行宽高、横坐标及公式范围一致；缓存只提供位置，不能替代助手来源证明。

## 历史、性能和资源

预览启用后使用独立的 `history-inline-1-v4-*` 派生数据库，关闭时使用 `history-v4-*`。升级首次扫描已有助手记录，加入完整字符公式的查找摘要；不再按共享上下标召回无关历史，标记被 Codex 隐去的行内变量使用完整表达式提示。它们只是候选，仍需整段来源核验；普通标识符和代码不会因为命中提示而被覆盖。不限制最近多少条历史，缓存淘汰后可按需重新加载；不复制会话正文到索引，也不改写 Codex 文件。

| 资源 | 上限 |
| --- | --- |
| 识别缓存（含无结果） | 128 项 / 8 MiB，按保留字符串估计 |
| 单条来源 / 单个源码行 / 单个候选 | 1 Mi UTF-16 字符 / 4096 / 1024 |
| 语法深度 / 每个表达式解析循环 | 16 / 256 |
| PNG 缓存 | 预览启用 1024 项，关闭 64 项；均为 32 MiB |
| 不可排版结果缓存 | 1024 项 / 256 KiB |
| UIA 行内几何 LRU | 1024 项；按窗格、字体、整行文字、矩形及公式范围区分 |
| 每次新增图片 / UIA 几何查找预算 | 25 ms / 35 ms；下轮继续，缓存命中继续返回 |
| 每批图片 | 预览最多 256 张，关闭最多 16 张；仍受单图 2 MiB / 整批 12 MiB 限制 |

这些时间预算是协作式检查，单次同步排版或 UIA 调用可能超时；不是硬实时保证。快速翻动仍合并旧请求、只处理最新视口。缓存记录的是可再生结果，不能代替新鲜的来源证明。

## 验证

- `npm run verify`：来源、语法、语义保留、混合正文、逐行视口、重复公式、代码保护、图像淘汰再生与原有块公式回归。
- `npm run test:windows-core`：原生来源保持、模式切换、行内列范围/原文/基线及异常 IPC。
- `npm run evaluate:inline`：确定性生成的 1250 个正例与 10000 个反例，独立报告边界及识别耗时；不等于真实模型输出的总体准确率。
- `npm run test:windows-inline-history`：真实捆绑 worker，240 个文件 / 9600 条回答，历史、缓存、追加、歧义、取消与持久化。
- `npm run test:windows-inline-geometry`：真实 Windows Terminal，生产 C# 定位器与独立 UIA 探针比较。
- `npm run test:windows-inline`：交互桌面回放，检查图片位置、相邻正文、选区、尺寸、流式稳定及开关。需解锁桌面。
- `node scripts/test-windows-live-stream.mjs --inline`：独立真实 Codex 连续两次无工具请求，核对无标记/显式行内公式、代码保护及历史图片的流式稳定性。不在常规验证或 CI 中自动发送模型请求。

实际通过项、时间测量及尚未完成的桌面检查见 [Windows 验证](windows-validation.md)。
